# Shell Scripting for System Administration

This repository is a collection of shell scripting projects designed to develop and showcase skills in Linux system administration and automation. Each project focuses on solving a practical, real-world problem using command-line tools and scripting.

## Purpose

The primary goal of this repository is to serve as a practical learning ground for mastering shell scripting and core Linux administration concepts. The projects contained here are exercises in building robust, automated solutions for common administrative tasks.

## Core Concepts & Skills Practiced

Through these projects, the following skills and concepts are explored and applied:

*   **Automation:** Writing scripts to eliminate repetitive manual tasks.
*   **System Administration:** Managing users, services, files, and logs.
*   **File System Management:** Organizing files and directories programmatically.
*   **Security:** Implementing security best practices through file permissions and ownership.
*   **Version Control:** Using **Git** and **GitHub** for code management, branching, and collaboration.

## Repository Structure

Each project is self-contained within its own directory. Inside each directory, you will find the project's source code along with a dedicated `README.md` file that details the specific learning objectives, requirements, and instructions for that particular project.

## Technologies Used

*   **Shell Scripting (Bash)**
*   **Core Linux/Unix Command-Line Tools**
*   **Git & GitHub**
